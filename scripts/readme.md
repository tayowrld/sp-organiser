Создание первого главного администратора:
`npm run admin:create`
Запускать из корня проекта. Скрипт создаёт аккаунт `admin@sp.local` со случайным паролем, выводит данные для первого входа. Можно передать `ADMIN_EMAIL` и `ADMIN_PASSWORD` через окружение; пароль — от 12 символов. Повторный запуск при существующем главном администраторе ничего не меняет.
Файл базы: [`data/app.sqlite`](../data/app.sqlite). Существующий пользователь не повышается автоматически, при занятой почте нужно выбрать другую.

[`backup.mjs`](backup.mjs): согласованная резервная копия SQLite с фотографиями, проверкой целостности и хранением последних 30 копий. Вход: `DATA_DIR`, `BACKUP_DIR`. Выход: датированный `.sqlite` в каталоге копий.

[`worker.mjs`](worker.mjs): вызывает локальное обслуживание раз в минуту и создаёт суточные резервные копии. Вход: окружение процесса, включая `MAINTENANCE_SECRET`; `INTERNAL_APP_URL` задаёт адрес приложения (по умолчанию `http://127.0.0.1:6553`, в Compose — `http://app:6553`). Запускается PM2 или Docker Compose; ошибки выводятся в журнал, процесс продолжает повторные попытки.

[`create-admin.mjs`](create-admin.mjs) учитывает `DATA_DIR`; для production запускайте с `node --env-file=.env scripts/create-admin.mjs`.
