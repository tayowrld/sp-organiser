PWA-ресурсы: manifest, иконки 192/512, service worker и стартовая страница без сети.

Service worker сохраняет оболочку `/work` и статические ресурсы Next.js. API и фотографии автоматически не кешируются. Последние рабочие данные отдельно хранятся в IndexedDB. Версия кеша `sp-shell-v3` должна совпадать с [`app/work/Register.tsx`](../app/work/Register.tsx). При изменении стратегии кеширования увеличьте версию в обоих файлах.

Push показывает общее сообщение; нажатие открывает рабочую смену. Для установки и уведомлений нужен HTTPS (localhost разрешён для разработки).

Иконки приложения: [`icon.svg`](icon.svg) — векторный знак «сп» с оранжевой точкой на графитовом фоне; [`icon-192.png`](icon-192.png) и [`icon-512.png`](icon-512.png) — PWA; [`apple-touch-icon.png`](apple-touch-icon.png) — iOS. [`app/favicon.ico`](../app/favicon.ico) содержит размеры 16, 32 и 48 px. Все варианты используют один рисунок с безопасными отступами для маскирования. Подключение — через metadata в [`app/layout.tsx`](../app/layout.tsx).
