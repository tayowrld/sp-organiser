Интеграционные проверки: `npm test`.

Тесты компилируют серверную логику во временный каталог, создают отдельную SQLite-базу и удаляют её после завершения. Проверяют права, обязательные подтверждения, возврат результата, повторную доставку, конфликты версий, занятие задачи отдела, передачу и закрытие смены, московскую границу дня, приостановку шаблона, ознакомление, динамическую просрочку и целостность резервной копии с фотографиями. Рабочая база проекта не используется.
