Модуль аутентификации и сессий.

Входные параметры:
- `email`, `password` для входа
- JWT-токен в cookie `session`

Выходные параметры:
- `login()` — установка сессионной cookie
- `logout()` — удаление cookie
- `getUser()` — текущий пользователь из cookie
- `hashPassword()`, `verifyPassword()` — хеширование
- `createToken()`, `verifyToken()` — JWT

Сценарии использования:
```ts
await login(email, password)
const user = await getUser()
await logout()
```

`getUser()` проверяет JWT и заново читает права и активность пользователя из SQLite при каждом запросе. JWT содержит только идентификатор. Отключённые пользователи не могут войти и теряют доступ в существующих сессиях. Автоматическое создание демонстрационных аккаунтов при входе отключено. Первого главного администратора создаёт `npm run admin:create`.
