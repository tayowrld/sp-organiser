Проверка готовности приложения `GET /api/health`.

Входные параметры: отсутствуют.
Выходные параметры: HTTP 200 при доступной SQLite, HTTP 503 при ошибке. Ответ не кешируется и не содержит данных пользователей.
Сценарии использования: Docker Compose проверяет готовность приложения перед запуском фонового обработчика.
