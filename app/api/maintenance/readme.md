`POST /api/maintenance` запускает ежедневные процедуры, проверку просрочек и доставку уведомлений. Требует `Authorization: Bearer MAINTENANCE_SECRET`; сравнение выполняется за постоянное время. Вызывается локальным PM2-процессом раз в минуту. Публичный доступ блокируется nginx.
