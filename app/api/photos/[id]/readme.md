`GET /api/photos/:id` возвращает байты фотографии события. Требуются действующая сессия и доступ к задаче либо ожидающая передача этому пользователю. Ответы имеют `private, no-store` и `nosniff`. Чужие и отсутствующие фотографии возвращают 404.
