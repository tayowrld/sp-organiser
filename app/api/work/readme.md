`GET /api/work` возвращает доступные пользователю задачи и связанные данные.

`POST /api/work` принимает JSON операции: `id`, `kind`, `userId` и поля действия. Проверяет сессию, Origin, права и размер запроса до 6 МБ. Возвращает `{ ok: true }` либо `{ error }` с кодом 400, 401, 403, 409 или 413. Повторный UUID не повторяет изменение. `subscribe` сохраняет подписку Web Push только для разрешённых HTTPS-сервисов доставки.
