Компонент `NavigationBar`:
Входные параметры:
- `user` — пользователь или `null`.
- `onLogout` — серверное действие выхода из системы.
Выходные параметры:
- шапка с брендом, навигацией и аккаунтом; на телефоне — нижняя панель навигации.
Сценарии использования:
`<NavigationBar user={user} onLogout={logout} />`
Все пользователи видят свои задачи и персонал. Флажок администратора добавляет раздел администрирования. Профиль доступен через имя в шапке. Активный раздел отмечен через `aria-current`. [`wrapper.tsx`](wrapper.tsx) загружает пользователя на сервере.
Логотип: надпись «сп» с квадратной акцентной точкой и надписью «организатор», выровненной по верхнему краю знака. На телефоне пять разделов помещаются в плавающую панель; раздел администратора подписан «Управление». Переходы остаются полноценными загрузками страниц для совместимости с офлайн-оболочкой service worker.

Логотип в header использует прежний Montserrat и оранжевую точку #ef8050; остальной интерфейс использует системный шрифт.

Подпись «ПЛАНИРОВАНИЕ РАБОТЫ» удалена. Положение элементов логотипа задаётся flex-выравниванием без transform; логотип не сжимается в шапке.
