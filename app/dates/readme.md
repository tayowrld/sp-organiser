Работа со сроками задач:
- `parseDeadline` принимает значение поля `datetime-local`, проверяет дату и возвращает время в миллисекундах Unix либо `null`. Время вводится по Москве независимо от часового пояса сервера.
- `formatDeadline` выводит числовой срок по-русски, с годом и временем по Москве.
Новые задачи сохраняют числовой срок в SQLite. Старые текстовые сроки сохраняются без изменений: год в них не указан, поэтому автоматически назначать его нельзя. Форматирование поддерживает старые записи до их уточнения.
