Рабочий экран `Workspace` по адресу `/work`.

Входные параметры:
- авторизованная сессия для `/api/work`;
- необязательные параметры `?tab=announcements` и `?create=task`.

Выходные параметры:
- мобильный интерфейс задач, смен, передачи, объявлений, отделов, уведомлений и истории;
- постоянная очередь действий в IndexedDB, включая прикреплённые фотографии.

[`storage.ts`](storage.ts) хранит последний срез данных и очередь. Изменения очереди выполняются транзакциями IndexedDB. Каждое действие получает UUID; повторная отправка безопасна. Синхронизация идёт после действия, при восстановлении сети, вручную и раз в минуту при открытом экране. Конфликт не перезаписывает сервер: пользователь видит ошибку, проверяет актуальные данные, удаляет конфликтующее действие и повторяет его. До подтверждения сервера карточка показывает ожидаемое состояние с явной отметкой ожидания. Это позволяет принять и завершить задачу без сети: действия отправятся последовательно с возрастающими версиями. При отказе первого действия зависимые действия остаются в очереди; удалите их перед повтором.

`Register` устанавливает service worker и сохраняет оболочку рабочего экрана и загруженные ресурсы. После первого онлайн-открытия доступен повторный запуск без сети. Вне сети работают просмотр загруженных данных и постановка действий в очередь; вход, получение новых данных и загрузка старых фотографий требуют сети. Отправка очереди возобновляется при открытом приложении. Push доставляется и при закрытом приложении, если браузер поддерживает его и пользователь дал разрешение.

При выходе локальные данные очищаются, несинхронизированная очередь требует подтверждения удаления. При истечении сессии очередь сохраняется до повторного входа в тот же аккаунт. При смене аккаунта локальный срез очищается. Не используйте офлайн-режим на общедоступном устройстве: загруженные рабочие данные доступны его владельцу.

Оформление: тёмные карточки, горизонтальная панель разделов с `aria-pressed`, крупные поля и кнопки. Семантика действий и очередь не зависят от оформления.
